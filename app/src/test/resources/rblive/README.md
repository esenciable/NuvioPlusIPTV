`esencial-sport` repository**, not this file.

- Refresh with `node tools/protocolVectors.cjs` in that repo, then copy the file here. Do not edit

`tests/protocolVectors.test.js` in the server repo re-runs every vector through the real JS
decoders, so a committed fixture that no longer matches the code fails CI there. When that happens,
regenerate, copy again, and expect the Kotlin tests in `app/src/test/.../sports/rblive/` to go red
until the port follows.

`expected` is a **subset** contract: every key present must match, extra keys the Kotlin model
carries are fine.
